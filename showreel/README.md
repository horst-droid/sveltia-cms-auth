# Studio HORST Showreels

Drei Motion-Reels, komplett in Canvas gerechnet, mit live synthetisiertem Ton (Web Audio). Es gibt keine Videodateien und keine Bibliotheken.

| Datei | Format | Inhalt |
| --- | --- | --- |
| `studio-horst-reel-9x16.html` | 1080 × 1920, 15 s | Instagram-Reel im Dither-Look mit Monster, vier Slots für eigene Bilder und Videos, Export als MP4/WebM |
| `studio-horst-reel-16x9.html` | 1920 × 1080, 15 s | Querformat-Reel: Passermarken, Raster-H, Leistungen, Formate |
| `claude-motion-reel.html` | 1920 × 1080, 15 s | Erste Demo |

Die Dateien sind für claude.ai-Artifacts geschrieben, deshalb fehlen `<html>`/`<head>`. Im Browser öffnen sie sich trotzdem direkt. Der Video-Export im 9:16-Reel funktioniert nur als Artifact (über die Downloads-Funktion).
